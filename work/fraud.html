Cost-Sensitive Healthcare Provider Fraud Detection

0.946ROC-AUC
74Features

Overview

I built a fraud-detection pipeline for healthcare providers using 74 engineered features from inpatient, outpatient, and beneficiary data. The model choice was tied to the cost of a wrong decision, not only to accuracy.

Problem

Fraud is rare, and a false alarm is not the same kind of mistake as a missed case. A ranking metric alone does not say whether investigating a claim is worth the cost.

What I built

  • 74 provider-level features from claims, beneficiaries, and reimbursement patterns
  • A comparison of logistic regression, random forest, gradient boosting, and an MLP
  • Cost-sensitive decision rules using reimbursement and investigation costs

Results

0.946 ROC-AUC. The cost-sensitive evaluation showed about a 99% modeled screening-cost reduction relative to the screening baseline used in that study.

Stack

Pythonscikit-learnPandasNumPy

What I learned

The operating point mattered as much as the AUC. A slightly weaker ranker can still be the wrong choice once investigation cost is in the decision.
