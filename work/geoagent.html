03 / Engineering decisions

Built to make execution inspectable.

Orchestration

Explicit workflow state

LangGraph connects planning, execution, verification, and reporting. Persisted runs retain steps, approval decisions, errors, timing, and tool outputs.

Analysis & retrieval

Tools calculate. Sources explain.

Python tools compute statistics and site-level time series. Retrieval attaches document excerpts and available page metadata to the research brief.

Service boundaries

One registry, two interfaces

FastAPI serves validated application contracts. The same registered tools are exposed through MCP for reuse outside the web interface.

Controlled execution

Bounded data operations

Tool argument validation, read-only DuckDB queries, path and size limits, and execution timeouts keep analysis operations constrained.

Implementation details & evaluation

React and TypeScript power the interface. FastAPI and SQLAlchemy persist sessions, runs, and tool results. SQLite supports the local demonstration; PostgreSQL and pgvector are supported for storage and retrieval.

A 50-task benchmark harness is included for evaluating a stated configuration. No aggregate success rate is claimed here. Optional OpenAI integration requires separate configuration and evaluation; the default planner and embeddings are deterministic.

Verification means the recorded outputs passed the application's implemented checks. It does not establish scientific validity or infer the cause of a vegetation change. GeoAgent supports evidence review; my satellite-model experiments remain a separate research project.
