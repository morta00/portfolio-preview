AI Automation Platform — Asjai Lou Casting

Client project. Source code and internal system access are private due to confidentiality. This page does not include endpoints, credentials, customer data, schemas, or private screenshots.

Overview

During an AI and automation internship I started a private platform that connects commerce workflows with a customer experience and an AI-assisted knowledge layer for the casting industry. The platform is still being extended.

Problem

Orders, account setup, fulfillment, and product knowledge were separate. The work is to connect those workflows and let an assistant answer from a curated knowledge base instead of an open-ended chat.

Currently developing

These capabilities are being developed or extended. Unfinished pieces are not described as already deployed.

  • Shopify and TikTok Shop workflow integration
  • API and webhook automation
  • Secure customer account activation and single-use account tokens
  • Idempotent order processing
  • Shipment and fulfillment workflows
  • Administrative content workflows
  • RAG over a curated casting-industry knowledge base
  • Agentic workflows that use tools and ask for human approval on sensitive actions
  • Error detection and recovery
  • Backend APIs, testing, and deployment

Technical decisions

Commerce events stay on the API and webhook boundary. Retrieval is limited to a curated knowledge base. Sensitive actions are meant to stop for a person instead of running unattended. I am not publishing the internal design beyond that.

Current progress

The internship ran May 2026 through August 2026. The platform is still evolving, so this page does not list launch metrics or a public demo.
