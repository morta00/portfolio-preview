AI Automation Platform — Asjai Lou Casting

Private system. Source code and internal product access are not public due to confidentiality. This page does not include endpoints, credentials, customer data, schemas, or private screenshots.

Overview

This is a private commerce and knowledge platform that is deployed. It connects store operations, customer workflows, fulfillment, and a curated casting-industry knowledge base. I am still extending it with agentic behavior.

What the deployed platform covers

  • Shopify and TikTok Shop workflows
  • API and webhook automation
  • Customer account activation, including single-use activation tokens
  • Idempotent order processing and fulfillment tracking
  • Content workflows, RAG, backend APIs, testing, and deployment

Still in development

These agentic pieces are not presented as finished:

  • Tool use and context-aware workflow decisions
  • Failure detection, retry, and recovery
  • Human approval for sensitive operations

Engineering decisions

Commerce events stay on the API and webhook boundary. Retrieval is limited to a curated knowledge base. Sensitive actions are meant to stop for a person instead of running unattended. I am not publishing the internal design beyond that.

Current progress

The internship ran May 2026 through August 2026. The platform is still evolving, so this page does not list launch metrics or a public demo.
